The rules
Agent blocks → an orange pulse travels the rail edge to its row (550ms), then the row rings once and fades. Your eye lands exactly where the event did.
Deck opens → cards stagger in at 70ms steps, loudest first — the read order is animated in.
Ctx meters fill on first paint and morph green→amber→red as they pass the thresholds.
Jump-to-needs-you → the same ring lands on the pane you arrive at.

Tradeoff: the most useful motion per frame — but each new event type needs its own choreography, so it grows with the app.
